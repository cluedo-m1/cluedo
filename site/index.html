Projet M1 MIAGE Apprentissage

Cluedo

Un jeu d'enquête façon Cluedo sur un campus universitaire fictif : des affaires générées automatiquement, à solution unique, dont chaque déduction est expliquée.

Dossier de projet (PDF) Code source Versions

Le projet

Dans les énigmes conçues à la main, plusieurs coupables sont parfois possibles, ou aucun. Cluedo génère des enquêtes inspirées de la vie d'une faculté (fuite de sujet d'examen, intrusion sur un serveur, disparition de matériel), vérifie qu'elles ont exactement une solution, règle leur difficulté et explique le raisonnement étape par étape.

Fonctionnalités

v0.1.0

Affaire tirée sous contraintes

Génère automatiquement une affaire cohérente, dont la solution est unique.

Algorithme : Satisfaction de contraintes (CSP / backtracking)

Steven Kamel

v0.1.0

Moteur de déduction

Déduit ce qui est possible à partir des indices et vérifie qu'une enquête est solvable.

Algorithme : Propagation de contraintes (AC-3) et retour arrière

Rafael Rodrigues

v0.1.0

Graphe spatio-temporel du campus

Carte du campus et déplacements horodatés des suspects, avec contrôle de cohérence des trajets.

Algorithme : Cheminement sur graphe orienté horodaté

Ilies Hamadene

v0.1.0

Filtrage d'hypothèses

Met à jour la liste des possibles quand le joueur formule une hypothèse sur le suspect, le lieu et l'objet.

Algorithme : Dénombrement des scénarios compatibles (retour arrière)

Nathan Eullaffroy

Architecture

Front Angular → API REST (Spring Boot) → back Java en architecture hexagonale → PostgreSQL.
